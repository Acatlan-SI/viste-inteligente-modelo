# Código de entrenamiento

Esta carpeta está destinada al código fuente usado para entrenar y evaluar los modelos de Viste Inteligente.

El repositorio actual contiene los artefactos ya generados en `models/`, pero no incluye los scripts originales ni el conjunto de datos. No se agrega código de entrenamiento reconstruido o supuesto. Cuando se incorpore el material original, documentar aquí sus dependencias, datos de entrada, comando de ejecución y artefactos producidos.

No guardar aquí credenciales, archivos `.env` ni datos personales. Los conjuntos de datos deben gestionarse de acuerdo con sus permisos y mantenerse fuera del repositorio cuando sean privados.
